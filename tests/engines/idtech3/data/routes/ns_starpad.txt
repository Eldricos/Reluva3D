# ns_starpad's way out, for sp-run -tour 5000 -replay (with -spare lando
# -spare cinematic20_kyle -spare cinematic20_lando, set helpUsObi 1). The
# tour rides the elevator up with Lando, sets off the hangar attack and
# brings him to the Lady Luck; here, from the tour's end:
#
# - The squads attacking the hangars, whose deaths send Lando on to the
#   ship (their death targets name hangar_dead...): the saber, close up,
#   as they keep behind cover.
# - The roof doors: each side's four use triggers, then the door's.
# - The fuel lines: two panels, each a number the other must match;
#   every pair is tried (a press only counts once the player has stood
#   still a moment), and the right one locks them.
# - The cockpit, where Reelo arrives, and the ship's gun, a panel
#   turret: taken at its panel (use, facing east), it turns from its own
#   facing (south) by the command's angles. Reelo and his eight thugs
#   must die within a minute; then the closing cinematics, the last of
#   which changes the level.
