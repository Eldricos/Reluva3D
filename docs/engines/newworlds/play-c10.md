# Star Trek: New Worlds: watched in play, bonus mission C10

The bonus Klingon mission C10 ("The Archer of Heaven", commented out in
`level.dat`), in a 37-minute recording with commentary titled "Klingon
Mission 15" (YouTube `SZQWcZi8mSc`). Observed behaviour; messages
paraphrased. October 2026.

## Which mission and map

- **No voice clips**: none of the 124 `KlingVO` clips match the recording.
- **Its briefing is one page**, over the Klingon emblem (0:16-0:36): the
  INCOMING message "from planetary operations: the house of Kirgat...",
  which is `cvr03.stb`'s string 74, in C10's part of that table (72 the
  title, 73 the stardate and a desert world, 75-77 the objectives: destroy
  the Romulan and Taubat colonies and a Romulan warbird). So the bonus
  missions use the shared `cvr03` table, as level.md says, with a single
  page and no speech.
- **The map**: the two mines reported exhausted (292, 364 and 276, 444) lie
  on deposits in five maps read as in [gmf.md](gmf.md#map-positions-in-the-game);
  the only desert one is **`f2`** (`deswrld`), and the terrain is tan sand
  with concrete. So C10 is played on F2's map, most likely.
- The colony starts already built (2:02, 52/50).
