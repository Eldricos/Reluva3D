# Star Trek: Generations

The `stgenerations` engine. Started from the template; fill this in as it grows.

## Games

| Game | Releases recognised | State |
|---|---|---|
| | | Not yet recognised |

Releases are recognised by the files in `kVariants`
(`src/engines/stgenerations/stgenerations.cpp`), made with `reluva --hash <files...>`.

## Using it

What a player needs: which folder to add, any settings, keys.

## Developer tools

`reluva-tool help stgenerations` lists its commands
(`src/engines/stgenerations/tools/`).

## Tests

- `reluva-tests stgenerations` runs its unit tests and its engine test
  (`tests/engines/stgenerations/`).
- A game-files test, when it has one: see
  [docs/DEVELOPMENT.md](../../DEVELOPMENT.md#engine-tests).
